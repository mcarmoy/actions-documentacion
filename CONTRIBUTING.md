# Guía de contribución

Gracias por querer contribuir a este proyecto.

## Cómo contribuir

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio: `git checkout -b feature/mi-cambio`.
3. Haz commit de tus cambios con mensajes claros.
4. Sube la rama y abre una Pull Request explicando qué has cambiado.

## Normas

- Revisa que tu cambio no rompa los workflows de GitHub Actions.
- Mantén actualizada la documentación si cambias algo importante.
